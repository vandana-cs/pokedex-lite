# ⚡ Pokedex Lite

A React + TypeScript app that displays Pokémon using PokéAPI.

---

## 🚀 Features

- Pokémon list from API
- Search by name
- Filter by type
- Pagination (Next/Previous)
- Favorites with localStorage
- Pokémon detail modal
- Responsive UI

---

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- PokéAPI

---

## ▶️ Run Locally

npm install  
npm run dev
